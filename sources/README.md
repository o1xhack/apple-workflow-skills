# 来源维护索引

manifest.json 是仓库来源、commit、Release 基线和文件映射的权威记录。reviews.json 单独记录审查结果；未审查、已审查和已采用不能混为一谈。
Apple 官方证据登记在 apple.json。运行模块中的自主改写见 ../docs/decisions.md。

许可证及便携来源副本位于 ../skills/apple-workflow-skills/sources。
未采用的上游网站、图片、安装器、仓库历史及无关技能不保留。需要复查时按准确 commit 重新获取。

本地 Apple UI 工作流为项目维护者提供的原创输入；不公开个人工作区路径或私有项目数据。
