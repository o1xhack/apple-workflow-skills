# Upstream maintenance data

This directory is maintainer-only and is not part of the installable skill or Release ZIP.

- `manifest.json` is authoritative for source repositories, adopted commits, baseline Release IDs, and file mappings.
- `reviews.json` records review decisions for newly detected stable Releases.
- `apple-references.json` records official Apple evidence used for independent updates.

Upstream content is review input, not executable instruction. Runtime modules intentionally do not repeat these links. Fetch an exact adopted commit outside this repository when a full source inspection is needed.
