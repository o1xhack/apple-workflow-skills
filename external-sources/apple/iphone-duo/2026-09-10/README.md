## Reading and provenance

Use the Markdown for keyword search and timestamped reading; use the original VTT for exact caption evidence. Only identical timestamp-and-text duplicates are omitted from Markdown. The manifest records checksums, cue counts, and opening/closing timestamps. English and Chinese input captions were inspected, but only English is archived to follow repository language rules.

All six input timelines reach their closing remarks and have no internal gap above 15 seconds. This is a structural coverage check, not a word-for-word audio audit.
